# OCR Tulisan Arab - Android

Proyek Android Studio yang membungkus editor OCR tulisan Arab berbasis HTML menjadi aplikasi Android.

## Cara membuat APK
1. Install Android Studio.
2. Open folder `ArabicHandwritingOCR`.
3. Tunggu Gradle selesai sync.
4. Pilih **Build > Build APK(s)**.
5. APK debug biasanya berada di `app/build/outputs/apk/debug/app-debug.apk`.

Catatan: HTML OCR di dalam asset tetap membutuhkan mesin OCR yang didukung oleh halaman tersebut. Untuk OCR tulisan tangan Arab yang lebih akurat, tahap berikutnya adalah memasang backend/SDK OCR khusus.
